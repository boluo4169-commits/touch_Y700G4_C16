# Y700四代触控优化 (touch_Y700G4_C16)

联想拯救者 Y700 第四代（骁龙8至尊 / SM8750）专用触控优化模块，直控 Novatek 触控芯片，为游戏场景深度调优。KernelSU / Magisk 通用，支持在线更新。

## ✨ 功能特性

- 🔥 360Hz 高采样 — 直控触控芯片，采样率拉满，跟手度显著提升
- 🛡️ 游戏防断触（v2.7 分场景守护） — 游戏内断触 2 秒自动兜底；非游戏场景完全放手，来电、滑出游戏不再失灵
- ⚡ 低延迟 — 关闭系统级触控延迟优化与防误触过滤，操作零拖沓
- 🔋 负载温度自适应调频 — 游戏满血运行，待机自动降频省电
- 📲 在线更新 — 内置 updateJson，KSU Manager 一键检查更新

## 📱 适用机型

| 项目 | 要求 |
| --- | --- |
| 机型 | 联想拯救者Y700 第四代（2025款） |
| 芯片 | 骁龙8至尊（SM8750） |
| 系统 | ColorOS 16 |

⚠️ 仅限第四代，其他代次（Y700 一代/二代/三代）硬件触控方案不同，请勿刷入。

## 📦 安装

1. 下载最新版 zip（[Releases](https://github.com/boluo4169-commits/touch_Y700G4_C16/releases)）
2. KSU Manager（或 Magisk）→ 模块 → 从本地安装 → 选择 zip
3. 重启生效

## 🔄 更新

- 自动：KSU Manager → 模块 → 检查更新，提示新版本后一键更新
- 手动：GitHub Releases 下载最新 zip 重新刷入（可直接覆盖）

## 🗑️ 卸载

- KSU Manager → 模块 → 移除并重启；或在 Recovery 中删除模块目录
- 模块自带 uninstall.sh，卸载时自动还原

## ⚙️ 配置

- `config` — 触控策略配置（采样率、场景守护开关）
- `perf.conf` — 调频策略（负载 / 温度阈值）

默认配置已调优，直接使用即可；如需微调，改完重启生效。

## 📜 版本历史

- v2.7 — 分场景守护：游戏内防断触兜底，非游戏完全放手，来电/滑出不再失灵
- v2.6 — 修复游戏滑出后触控失灵、来电断触问题；更名 ColorOS16 专用
- 更早版本：360Hz 高采样、游戏模式、调频策略逐步完善

## ❓ 常见问题

**Q：怎么确认模块生效了？**
A：模块状态显示已启用，且触控设置中采样率相关选项生效即为正常。

**Q：游戏里还是偶尔断触？**
A：v2.7 已加入游戏内 2 秒兜底逻辑，若仍有问题，在酷安帖子反馈时说明游戏名称和场景，方便复现定位。

**Q：更新时提示失败？**
A：多为网络问题，可稍后重试或手动下载 Releases 里的 zip 安装。

**Q：其他代的 Y700 能刷吗？**
A：不能，模块仅适配四代触控方案，刷入可能异常。
