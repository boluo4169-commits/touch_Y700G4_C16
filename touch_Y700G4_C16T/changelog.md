# touch_Y700G4_C16T v3.0T 单触控版

**v3.0T 修复版**：游戏内音量键弹窗卡顿问题。

## v3.0T 修复内容
- 修复：游戏内按音量键 → 弹窗出现 → 游戏卡住、音量调不了
  - 原因：模块强制开启 IC 手势引擎（gesture_control=1），与系统音量面板交互冲突
  - 解决：移除 gesture_control 写入，手势引擎保持系统默认
- 影响：360Hz 高采样、游戏模式、低上报阈值、防断触守护全部不变

## 触控能力
- 直控 Novatek /proc 节点：360Hz 高采样、游戏模式、游戏边缘、低上报阈值
- 框架层属性：关误触防护、关边缘抑制、压输入延迟、ColorOS 游戏空间增强
- 帧率档位：fps=120 / 144 / 165（编辑 config 后重启生效）
- 分场景守护：
  - 游戏内 (gm=2)：参数被重置 1 秒内自动恢复，防断触兜底
  - 非游戏场景（来电/滑出游戏/桌面）：完全放手，修复屏幕失灵
- 卸载无残留：停守护、清 persist 属性、复位节点

## 说明
- 已移除：perf_daemon / perf.conf（调频调度），不碰 CPU 频率
- 已移除：gesture_control 强制开启（v3.0 修复）
- 适合已有独立调频方案（调度器/Scene/自定义性能配置）的用户
- 与主模块 touch_Y700G4_C16 二选一安装，勿同时启用

## 安装
- KernelSU Manager / Magisk 直接刷入（flat 结构）
- 路径：/data/adb/modules/touch_Y700G4_C16T/
