# touch_Y700G4_C16 v3.0
**v3.0 修复版**：游戏内周期性触控冻结 2~3 秒。

## v3.0 修复内容
- 修复：游戏进行中触控每隔一段时间完全失灵 2~3 秒后自动恢复
  - 根因：性能守护在切性能档时强制写回 game_mode=1，与系统（游戏内写 game_mode=2）来回拉锯，触控芯片反复停在配置切换窗口
  - 解决：perf_daemon.sh 彻底移除所有 game_mode 写入，game_mode 由系统独占管理
- 优化：断触恢复从“三节点全量重写”改为“哪个异常只写哪个”，减少 I2C 写入，缩小触控芯片的配置切换窗口
- 影响：开机初始化也不再写 game_mode；高采样率/边缘抑制/阈值等守护逻辑不变

## 触控能力
- 直控 Novatek /proc 节点：360Hz 高采样、游戏模式、游戏边缘、低上报阈值
- 框架层属性：关误触防护、关边缘抑制、压输入延迟、ColorOS 游戏空间增强
- 负载温度自适应调频（perf_daemon）：游戏满血、待机省电、高温保护
- 帧率档位：fps=120 / 144 / 165（编辑 config 后重启生效）

## 安装
- KernelSU Manager / Magisk 直接刷入
- 模块路径：/data/adb/modules/touch_Y700G4_C16/
